총 **128장**입니다. 각 프롬프트는 그대로 복사해 쓸 수 있고, 공통 스타일이 이미 들어 있습니다.

## 코덱스에서 쓰는 방법

1. **아래 수정 프롬프트로 A04, A01, A02, A03 순서로 확정**합니다. 여기서 앱의 인상이 결정됩니다.
2. 나머지를 만들 때 **A01, A02를 참고 이미지로 함께 넣습니다.** 캐릭터가 달라지면 세트가 깨집니다.
3. 표의 **파일명 그대로** 저장합니다. 폴더는 `web/public/assets/game/` 아래입니다. 그대로 가져오시면 제가 바로 앱에 연결합니다.
4. 배경이 **투명**인 항목은 PNG 투명 배경으로 저장합니다. 배경이 흰색으로 나오면 다시 만들지 말고 알려 주세요. 제가 처리할 수 있는지 확인합니다.
5. 코덱스가 파일을 읽을 수 있으면 같은 폴더의 `이미지_프롬프트_전체.json`을 주면 한 번에 진행하기 쉽습니다.

## 지켜야 할 규칙

- **글자 금지:** 이미지 안에 글자와 숫자를 넣지 않습니다. 노선 번호와 문구는 앱이 얹습니다. 그래야 4개 언어가 됩니다.
- **베끼기 금지:** 타요, 듀오링고, 포켓몬, 카카오프렌즈 같은 기존 캐릭터와 닮으면 다시 만듭니다.
- **제주 소재:** 귤, 오름, 현무암, 돌담, 바람, 바다, 유채, 동백을 씁니다. **해녀와 돌하르방은 넣지 않았습니다.** 문화·상표 위험 때문입니다.
- **실제 회사 금지:** 실제 버스 회사 로고, 차량 번호, 기사 얼굴을 넣지 않습니다.
- **저작권:** AI가 만든 대표 캐릭터는 권리 보호가 약합니다. 확정한 버스 말은 나중에 사람이 벡터로 다시 그리는 것을 권합니다.

## 이미지로 만들지 않는 것

아래는 제가 코드(CSS, SVG)로 만듭니다. 이미지로 만들면 작게 깨지거나 언어와 다크 모드에 대응하지 못합니다.

| 항목 | 이유 |
|---|---|
| 노선 등급 도형 칩 (원, 세모, 화살 머리, 꽃잎) | 글자와 함께 선명해야 함 |
| 시간대 띠 (새벽, 낮, 노을, 밤) | 얇은 색띠라 CSS로 충분 |
| 실제 지도 | 지도 타일을 쓰며 지리를 꾸미지 않음 |
| 타도 돼 카드의 숫자와 글자 | 실시간 값 |
| 도장의 흑백 상태와 색 번짐 | 컬러 이미지에서 효과로 처리 |
| 표정의 다른 노선색 | 간선 이미지를 색만 바꿈 |
| 결행, 변경, 사고 화면 | 일부러 이미지 없음 |
