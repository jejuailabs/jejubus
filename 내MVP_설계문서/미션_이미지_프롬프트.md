# 미션 이미지 교체 목록

지금은 `web/public/art/quest/` 에 도형으로 만든 임시 SVG가 들어 있습니다. 같은 이름으로 그림을 만들어 주시면 교체합니다.

- 교체 방법: 파일을 `web/public/art/quest/이름.webp` 로 넣고, `web/public/quest.js`의 `SLOT_EXT`에 `'이름':'webp'`를 추가합니다.
- 공통 스타일: 기존 A01~A04와 같은 구아슈·종이 오리기, 외곽선 없음, 둥근 형태, 글자·숫자·로고 금지, 1024×1024.
- 기존 공통 문장(`이미지_프롬프트_전체.md`)을 앞에 붙여 쓰면 됩니다.
