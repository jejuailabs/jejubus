## 켜려면 사용자가 해야 하는 일

키는 Claude가 입력하지 않는다. `web/.env.local`과 Vercel 환경변수에 사용자가 직접 넣는다. 기본값은 모두 꺼짐이며, 켜지 않으면 해당 버튼이 보이지 않는다.

| 기능 | 해야 할 일 | 환경변수 |
| --- | --- | --- |
| 카카오 로그인 | 전용 앱 `제주버스`(ID 1640414) 콘솔 설정 완료: 로그인 ON, 닉네임 필수 동의, 운영·로컬 리다이렉트 URI 등록. 키 입력만 남음 | `KAKAO_LOGIN_REST_KEY`, `KAKAO_CLIENT_SECRET`, `KAKAO_LOGIN_ENABLED=true` |
| 카카오톡 알림 | `talk_message` 이용 중 동의 설정 완료. `/admin` 문의 탭에서 연결 | `KAKAO_ALERT_ENABLED=true` |
| 카카오톡 상담 | 채널 생성, 공개·채팅 켜기 | `KAKAO_CHANNEL_ID` |
| 블로그 후기 | Application jejubus-blog 등록 완료, 로컬 실제 검색 확인. Vercel 키 입력 남음 | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `BLOG_ENABLED=true` |
| 네이버 로그인 | 개발자센터 등록, Callback `https://jejubus.vercel.app/auth/naver/callback` | `NAVER_LOGIN_CLIENT_ID`, `NAVER_LOGIN_CLIENT_SECRET`, `NAVER_LOGIN_ENABLED=true` |

카카오 로그인은 전용 앱을 쓰고, 지도·장소·길찾기는 무료 쿼터가 있는 기존 `KAKAO_REST_KEY`를 그대로 쓴다. 두 키를 바꿔 넣으면 안 된다. 네이버 키는 무료 사용량과 요금 조건을 확인한 뒤 켠다(CLAUDE.md 8번).

## 일부러 하지 않은 것

- **결제(Step 11):** 제주버스에는 파는 상품이 없고 교안의 '가고 싶어요' 요청 흐름도 없다. 계좌이체 안내에는 실제 계좌가, 토스 테스트에는 키가 필요하다. 상품을 정하기 전에는 만들지 않는다.
- **Padlet 제출:** 수강생 본인 이름으로 올리는 글이라 직접 올린다. 올릴 때 키, 이메일, 회원번호, 주소창을 가린다.
- **네이버 로그인:** 개발자센터에서 키를 받아야 해서 꺼져 있다.
