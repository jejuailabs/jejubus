## 현장 정보 비교 — 후속 조사

동일 날짜·노선·방향·정류소에 대해 공식 확인 시각, 각 지도앱 조회 시각과 표시, 실제 관찰 결과를 구분해 기록합니다. 기점 출발시간을 정류소 도착시간과 비교하지 않습니다. 표본 수·비교 방법 확정 전 정확도 향상 수치를 홍보하지 않습니다.

시험 기록에는 실행일, 담당자, 구현 버전, 실제 결과, 통과/실패, 재검사 결과를 추가합니다. 수업의 테스트 완료 기준은 실제 실행 후에만 체크합니다.
