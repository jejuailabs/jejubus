## Vercel

- 대상: [jejuai / jejubus](https://vercel.com/jejuai/jejubus/settings/environment-variables), 현재 Hobby.
- 운영 도메인: `jejubus.vercel.app`. `APP_ORIGIN=https://jejubus.vercel.app`.
- Production에 Secret 25개 저장. Google 2, TAGO 3, 카카오 3, ODsay 3, 예시 글 플래그 1, OpenAI·AI 플래그/한도 4, Firebase 8, 운영 Origin 1.
- Windows 로컬 파일 경로·HOST·PORT는 Vercel에 복사하지 않았다. Firebase Admin JSON은 해당 프로젝트의 서버 Secret으로만 저장했다.
- 환경변수 등록은 배포 완료를 뜻하지 않는다. 현재 서버는 로컬 SQLite를 사용하며, Vercel용 영속 DB·서버리스 OAuth 상태 보관·HTTP 진입점 적용 및 운영 도메인 Google 리디렉션 확인이 남아 있다.
- 기존 Firebase 프로젝트의 Blaze 여부를 확인하기 위해 **무료 Cloud Billing 조회 API**도 시도했으나 서비스 비활성화 응답을 받았다. API나 결제를 활성화하지 않았으며, 최종 요금제는 Firebase 콘솔에서 확인했다.

## TAGO

- 사용자 승인 후 국토교통부 TAGO 노선·정류소·도착·위치 **4종 모두 개발계정 승인 완료**. 만료예정일 2028-10-24.
- 제공 도시 목록에서 `39 / 제주도` 확인. 도시코드를 임의로 가정하지 않았다.
- `201` 검색: 20개 노선 항목. 선택 노선 `JEB405320111`: 경유 정류장 187개, 실제 차량 좌표 4대 응답.
- `탐라장애인 종합복지관[남]` 정류장: 281번 도착예정 120초·잔여 정류장 1개 응답을 확인했다. 이 숫자는 그 시점의 응답이며 고정 안내가 아니다.
- 브라우저의 201번 노선 화면에서 `운행 위치 4대`와 실제 지도를 확인했다.
- 앱의 전체 TAGO 요청은 일일 1,000회로 제한하며 공급자 요청은 캐시·중복 제거를 적용한다.

## 카카오

- 현재 계정의 기존 `펀제주` 앱(ID 1432936)에 무료 쿼터가 적용돼 있음을 콘솔에서 확인했다. **카카오맵 유료 API는 사용 안 함**이며 비즈월렛·유료 전환 설정을 변경하지 않았다.
- 기존 REST 키만 제주버스 서버에서 재사용한다. 펀제주와 무료 쿼터를 공유한다. 카카오 로그인·관리자 키·권한·기존 키 허용 IP 설정을 변경하지 않았다.
- 앱 제한: 장소 검색 100회/일, 버스 경로 100회/일. 공급자 무료 쿼터 소진 시 중단하며 자동 유료 전환이나 다른 제공자로의 자동 재시도는 없다.
- 실제 `제주국제공항`, `제주시청` 장소명 검색·결과 선택·길찾기 성공.
- 카카오가 도보 단계를 생략하는 응답에서도 `전체 거리 - 버스 구간 거리`로 제공자 데이터의 도보 거리를 반영한다. 도보 소요시간이 제공되지 않으면 임의로 만들지 않는다.

## ODsay와 OpenAI

- ODsay `jejubus` Basic, 30회/일·0원·기간 무제한. 앱은 길찾기·선형 조회 합계 25회/일로 제한한다.
- 허용 URI에 `localhost:3000`, `jejubus.vercel.app` 저장. 설정 완료 안내를 확인했다. 유료 Flex·결제수단을 설정하지 않았다.
- 기본 길찾기는 현재 카카오이며, ODsay는 선택 가능한 대체 어댑터다. 오류나 한도 초과 때 자동 전환하지 않는다.
- 사용자의 요청으로 다른 로컬 프로젝트에서 기존 `OPENAI_API_KEY`를 찾아 로컬과 지정된 Vercel 프로젝트에 저장했다. 키 자체나 원본 파일의 다른 설정은 외부 문서·로그에 기록하지 않았다. 유료 추론과 모델 선택은 별도 비용 승인 전까지 비활성이다.

## 남은 작업

1. Firebase Blaze의 공유 무료 한도·초과 요금·사용 예산과 기간에 대한 명시적 승인 후 DB 연결과 실제 검증.
2. Vercel 호환 영속 저장소·OAuth 상태·실행 진입점을 적용하고 검증한 뒤 GitHub 푸시/배포.
3. 실제 Google 로그인·로그아웃, 운영 콜백 URI와 커뮤니티 계정 기능 검증.

현재 확인한 API/무료 콘솔 작업 외에 OpenAI 추론, Firestore 문서 읽기·쓰기, 유료 전환, GitHub 자동 배포는 실행하지 않았다.
