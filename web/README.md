# 제주버스

Node.js 22.13 이상. 실제 지도와 버스 정보·커뮤니티를 연결하는 로컬 웹앱이다.

```powershell
cd web
npm run dev
```

앱: http://localhost:3000/ · API 발급 및 로컬 설정: http://localhost:3000/setup

TAGO 4종 승인·키 연결과 카카오 장소 검색·버스 길찾기 실연동을 완료했다. 제주 도시코드 39, 201번 노선·경유 정류장·실제 운행 차량 좌표 및 정류장 도착 응답을 확인했다. ODsay `jejubus` Basic도 실제 제주 길찾기와 지도 경로선을 검증했으며, 무료 30회/일 중 앱은 최대 25회/일로 제한한다. Google OAuth의 로컬 실제 로그인과 사용자 프로필 표시를 확인했다. OpenAI 키는 저장했으나 유료 추론은 비활성이다.

발급 순서·비용 조건·검증 상태는 [09 API 발급과 실연동 검증](../내MVP_설계문서/09_API발급과_실연동_검증.md), 설정 완료 목록은 [10 환경변수 연결 현황](../내MVP_설계문서/10_환경변수_연결현황.md)에 있다. 키는 `web/.env.local` 또는 로컬 설정 화면에 입력한다. `.env.local`, SQLite DB 및 비밀값은 Git에서 제외한다. Vercel `jejuai/jejubus` Production Secret 27개를 저장했다. 사용자 승인 후 기존 Firebase Blaze에 실제 문서 저장·재조회와 커뮤니티/세션/OAuth/한도 공유를 검증했다. 운영은 Firestore, 로컬 오프라인 개발은 SQLite를 선택한다. `api/index.mjs`와 `vercel.json`으로 서버리스 실행을 준비했고 로컬 Vercel 빌드를 통과했다. 운영 주소는 https://jejubus.vercel.app/ 이며 Google 로그인·게시글/답변 저장·실시간 버스·장소/길찾기를 실제 검증했다. 운영 배포 결과는 10번 문서에 기록했다.

검증:

```powershell
npm test
npm run check
```

외부 호출 없는 UI 검증용 서버: `node test/qa-server.mjs`. 출력된 임시 localhost 주소를 사용한다. 모든 계정·버스·시간은 `QA` 모의 데이터이며 메모리 DB만 쓴다. 15분 후 자동 종료한다. 이 서버를 서비스용으로 실행하지 않는다.

유료 API/AI, 결제 계정, 호스팅·DB·도메인 배포는 기본 비활성이다. 추가 비용이 발생하거나 불확실한 실행은 서비스·요금·예산·기간별 사용자 승인 이후에만 진행한다.

장소 자동완성: 출발지·도착지에서 2자 이상 입력 후 450ms가 지나면 실제 카카오 장소 후보를 최대 7개 표시한다. 장소명·주소와 키워드 강조, 방향키/Enter 선택, Esc/바깥 클릭 닫기, 한글 조합 입력 처리를 지원한다. 같은 검색어는 브라우저 메모리에 5분 캐시하고 동시 요청을 합친다. 후보 선택 시 좌표를 확정하며 두 지점이 모두 확정되면 바로 길찾기를 요청한다. 기존 제공자 무료 한도와 오류 처리는 유지한다.


실시간 버스 위치 메뉴는 노선 번호 검색 → 운행 방향 선택 → TAGO 차량 좌표 표시 흐름입니다. 파란 버스 아이콘과 회색 정류장 점을 구분하고, 차량 위치 수신 시각과 20초 자동 갱신 안내를 표시합니다. 보이는 화면에서만 주기적으로 조회하며, 조회 실패 시 마지막 위치를 유지하고 갱신 지연을 알립니다. 노선 변경 중 이전 요청의 응답은 무시합니다. 차량 좌표의 수신 시각은 제공처의 GPS 측정 시각을 의미하지 않습니다.

AI 버스 상담은 `web/lib/bus-chat.mjs`와 `/api/chat`으로 구현했습니다. 자유 질문을 OpenAI Responses API의 함수 호출로 해석하고, TAGO 노선·차량·경유 정류장·도착 또는 카카오/ODsay 길찾기 결과를 조회한 뒤 근거 ID가 연결된 답변을 생성합니다. 운행 방향이나 장소가 모호하면 후보를 선택하도록 합니다. 대화는 브라우저 메모리에만 보관하고, 위치·선택 정보는 체크한 경우에만 함께 전달합니다. Google 로그인, 같은 출처 요청 검사, 네 언어 UI를 적용합니다. 기존 조건 검색은 유료 추론 없이 규칙 기반으로 유지합니다.

2026-10-24 현재 새 상담 기능은 모의 모델·모의 교통 응답으로 전체 흐름과 34개 자동 테스트를 검증한 상태입니다. 실제 OpenAI 호출과 운영 활성화 검증은 별도 비용 승인 후 진행해야 합니다. `AI_ENABLED=true`, `AI_BILLING_APPROVED=true`, `OPENAI_MODEL=gpt-5.4-mini`, `AI_APPROVAL_ID`, `AI_APPROVAL_UNTIL` 조건이 모두 맞아야 동작합니다. 승인 만료 시 자동 중단하며, 운영 설정 화면에서 임의 활성화할 수 없습니다. 키나 승인 ID만 있다고 비용 승인을 받은 것으로 취급하지 않습니다.

AI 요청은 질문당 모델 호출 최대 2회, 호출당 요청 JSON 26,000바이트·출력 900토큰으로 제한합니다. 승인 기간 전체 최대 100회, 하루 최대 20회 모델 호출을 Firestore의 공유 카운터로 선예약하고 실패도 차감합니다. 승인 기간 카운터는 자정이나 인스턴스 재시작으로 초기화되지 않습니다. 자동 재시도·대체 유료 모델·유료 웹 검색·자동 갱신 구독을 사용하지 않습니다. GPT-5.4 mini 공식 단가 확인: https://developers.openai.com/api/docs/models/gpt-5.4-mini (2026-10-24 입력 $0.75/백만 토큰, 출력 $4.50/백만 토큰). 동일 키의 다른 앱 사용량은 이 앱의 카운터로 제한할 수 없습니다.

모바일 보완: 320px 소형 화면, 390px 세로, 844×390 가로, 768px 태블릿 메뉴와 상담창을 브라우저 뷰포트로 검사했습니다. 작은 화면의 520px 최소 높이를 제거하고 하단 메뉴가 콘텐츠를 덮지 않도록 배치합니다. 주요 버튼은 최소 44px 터치 높이, 입력 글자는 16px이며, 안전 영역과 짧은 화면 높이에 대응합니다. 실제 iOS·Android 기기와 가상 키보드 동작 검증은 별도로 필요합니다.
